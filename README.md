# basicstack-skills
Basic Stack skill.md library for basicstack.de and basicstack.org.

## Installation

Install a skill using [paperclip](https://github.com/basicstack/paperclip):

```bash
npx skills add https://github.com/al66/basicstack-skills/tree/main/skills --skill 'pocket-id-api'
```

## Available skills

- Pocket ID API: `/skills/pocket-id-api/skill.md`
